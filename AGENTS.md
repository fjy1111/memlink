## Python environment

This repository uses a project-local virtual environment:

`E:\memlink\.venv`

Do not use Conda or the global Python interpreter.

Use:

`.\.venv\Scripts\python.exe`

Run tests with:

`.\.venv\Scripts\python.exe -m pytest -q`

Install packages only into `.venv`.

Use the repository-local interpreter:

`.venv\Scripts\python.exe`
